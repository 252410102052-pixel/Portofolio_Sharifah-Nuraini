# Portofolio_Sharifah-Nuraini
Website portfolio pribadi yang dibuat untuk menampilkan profil, pendidikan, keterampilan, pengalaman organisasi, dan proyek yang pernah dikerjakan.

Website ini dirancang dengan tampilan responsif agar dapat diakses melalui perangkat desktop, tablet, dan mobile.

Bahasa Pemograman yang Digunakan
- HTML
- CSS
- JavaScript
